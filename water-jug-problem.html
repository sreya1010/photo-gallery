Water Jug Problem: State Space Search Analysis

Problem Statement

Given two jugs with capacities of 3 liters and 5 liters, and a goal of measuring exactly 4 liters, find the sequence of operations to reach the goal state.

Part A: Basic Operations

Fundamental Actions for State Space Evolution:

  • Fill Jug A (3L): Fill the 3-liter jug completely
  • Fill Jug B (5L): Fill the 5-liter jug completely
  • Empty Jug A: Empty the 3-liter jug completely
  • Empty Jug B: Empty the 5-liter jug completely
  • Pour A → B: Pour from 3L jug to 5L jug until B is full or A is empty
  • Pour B → A: Pour from 5L jug to 3L jug until A is full or B is empty

State Representation: (a, b) where a = amount in 3L jug, b = amount in 5L jug

Initial State: (0, 0)

Goal State: Any state where either jug contains exactly 4 liters

Part B: State Space Model

State Space Structure:

  • States: All possible combinations (a, b) where 0 ≤ a ≤ 3 and 0 ≤ b ≤ 5
  • Total possible states: 4 × 6 = 24 states
  • Valid goal states: (3, 4), (4, 0), (4, 5), etc.
  • Transitions: Each state can transition to multiple states based on the 6 operations

This model guides the search process by providing a finite, well-defined space to explore systematically.

Part C: Algorithm Implementation and Comparison

A* Heuristic Function:

h(state) = |4 - a| + |4 - b| where a and b are the amounts in each jug.

This heuristic estimates the minimum distance to any goal state containing 4 liters.

It is admissible (never overestimates) and consistent, making A* optimal.
